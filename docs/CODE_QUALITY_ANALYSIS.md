### 改进建议 ⚠️

#### 1. 单元测试与集成测试分离
**现状**: 测试代码混合在一起  
**建议**:
```go

// 集成测试打标签

// 运行方式：
// go test -short ./...        # 只运行快速单元测试
// go test -tags=integration   # 运行集成测试
```

#### 2. 错误处理规范化
**现状**: 有些地方使用 `errors.New()`，有些用 `fmt.Errorf()`  
**建议**:
```go

var ErrTopicNotFound = errors.New("topic not found")

// 包装错误
return fmt.Errorf("failed to create topic: %w", err)
```

**建议**:
